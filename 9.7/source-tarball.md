# Install Percona Server for MySQL from a source tarball

Fetch and extract the source tarball. For example:

```
wget https://downloads.percona.com/downloads/Percona-Server-9.7/Percona-Server-9.7.2-3/source/tarball/percona-server-9.7.2-3.tar.gz
```

Unpack the download to get the source code:

```
tar xfz percona-server-9.7.2-3.tar.gz
cd percona-server-9.7.2-3
```

To complete the installation, follow the instructions in [Compile Percona Server for MySQL from Source](https://docs.percona.com/percona-server/9.7/compile-percona-server.html).
