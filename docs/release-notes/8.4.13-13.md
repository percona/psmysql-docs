# Percona Server for MySQL 8.4.13-13 (2026-11-24)

Get started with [Quickstart Guide for Percona Server for MySQL].

[Percona Server for MySQL 8.4.13-13 :octicons-link-external-16:](https://www.percona.com/software/mysql-database/percona-server) includes all the features and bug fixes available in the MySQL 8.4.13 Community Edition in addition to enterprise-grade features developed by Percona.

## Release highlights

Improvements and bug fixes introduced by Oracle for MySQL 8.4.13 and included in Percona Server for MySQL are the following:

* **Stale Adaptive Hash Index (AHI) Data Fix:** Resolved an issue where point lookups returned outdated data after a modified table's tablespace was discarded and replaced with an older imported image. Outdated AHI entries are now safely bypassed as cache misses, forcing the system to perform a standard B-tree traversal.
* **Failed Tablespace Import Cleanup:** Prevented an assertion error that could occur during page eviction if an `ALTER TABLE ... IMPORT TABLESPACE` command failed. The cleanup process now correctly preserves the index space identifier so that leftover AHI entries can be properly purged.
* **Fatal Page Reorganization Mismatches:** Addressed a severe vulnerability where InnoDB would ignore size discrepancies during page reorganization without logging the necessary redo data, risking database corruption or recovery failures after a crash. These mismatches are now appropriately classified as fatal errors to prevent inconsistent states from persisting.
* **Self-Referencing Foreign Keys:** Patched a bug that previously caused problems when attempting to rename columns bound by self-referencing foreign key constraints.

Find the complete list of bug fixes and changes in the [MySQL 8.4.13 release notes :octicons-link-external-16:](https://dev.mysql.com/doc/relnotes/mysql/8.4/en/news-8-4-13.html).

## Builds and packaging

Percona Server for MySQL releases include a mixture of PGO and non-PGO builds. Where Profile-Guided Optimization (PGO) is enabled, the compiler uses runtime profiling data from representative workloads to guide optimization, which can improve throughput and reduce latency compared with non-PGO builds.

* See [Profile-Guided Optimization (PGO) and non-PGO builds](../pgo.md) for benefits, considerations, and which build you receive for your platform.
