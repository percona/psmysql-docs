# Percona Server for MySQL 8.4.13-13 (2026-11-30)

Get started with [Quickstart Guide for Percona Server for MySQL].

[Percona Server for MySQL 8.4.13-13 :octicons-link-external-16:](https://www.percona.com/software/mysql-database/percona-server) includes all the features and bug fixes available in the MySQL 8.4.13 Community Edition in addition to enterprise-grade features developed by Percona.

## Release highlights

Improvements and bug fixes introduced by Oracle for MySQL 8.4.13 and included in Percona Server for MySQL are the following:

- **Stale Adaptive Hash Index (AHI) Data Fix:** Resolved an issue where point lookups returned outdated data after a modified table's tablespace was discarded and replaced with an older imported image. Outdated AHI entries are now safely bypassed as cache misses, forcing the system to perform a standard B-tree traversal.
- **Failed Tablespace Import Cleanup:** Prevented an assertion error that could occur during page eviction if an `ALTER TABLE ... IMPORT TABLESPACE` command failed. The cleanup process now correctly preserves the index space identifier so that leftover AHI entries can be properly purged.
- **Fatal Page Reorganization Mismatches:** Addressed a severe vulnerability where InnoDB would ignore size discrepancies during page reorganization without logging the necessary redo data, risking database corruption or recovery failures after a crash. These mismatches are now appropriately classified as fatal errors to prevent inconsistent states from persisting.
- **Self-Referencing Foreign Keys:** Patched a bug that previously caused problems when attempting to rename columns bound by self-referencing foreign key constraints.

Find the complete list of bug fixes and changes in the [MySQL 8.4.13 release notes :octicons-link-external-16:](https://dev.mysql.com/doc/relnotes/mysql/8.4/en/news-8-4-13.html).

## New features

- [PS-10110](https://perconadev.atlassian.net/browse/PS-10110): Added improved MyRocks statistics that can be shared with the query optimizer, helping it choose better query plans.

- [PS-11106](https://perconadev.atlassian.net/browse/PS-11106): Added the [Keyring Encrypted File component](use-percona-keyring-encrypted-file.md).

- [PS-11392](https://perconadev.atlassian.net/browse/PS-11392): Added support for Password-Based Key Derivation Function 2 (PBKDF2), a stronger method for protecting passwords, backported from version 9.7.

- [PS-11419](https://perconadev.atlassian.net/browse/PS-11419): Added support for proxied users with long group names or IDs in the OpenID Connect (OIDC) plugin.

## Improvements

- [PS-10355](https://perconadev.atlassian.net/browse/PS-10355): Audit Log Filter logs query text in client character set instead of UTF-8, which produced invalid UTF-8 in JSON logs and audit_log_read()

- [PS-10452](https://perconadev.atlassian.net/browse/PS-10452): Added a “dropping table” thread state so DROP TABLE operations are no longer shown as “checking permissions”.

- [PS-11118](https://perconadev.atlassian.net/browse/PS-11118): Support for Regular Expressions (Regex) in Audit Log Component Filters.

- [PS-11495](https://perconadev.atlassian.net/browse/PS-11495): Reduced contention on internal block mutexes, which improves performance under heavy concurrent workloads.

- [PS-11568](https://perconadev.atlassian.net/browse/PS-11568): The OpenID (OIDC) authentication plugin ships with an installation script, so you no longer have to install and configure this plugin manually.

- [PS-11929](https://perconadev.atlassian.net/browse/PS-11929): Improved how InnoDB tracks read-write lock holders, which reduces overhead and improves performance under heavy workloads.

## Bug Fixes

- [PS-8313](https://perconadev.atlassian.net/browse/PS-8313): Stopping replication on a semi-synchronous replica caused the source to log a spurious `[MY-013129]` error ("Got an error reading communication packets", MY-001158) in the error log. The error no longer appears.

- [PS-9704](https://perconadev.atlassian.net/browse/PS-9704): Fixed an issue where the LDAP authentication plugin could not handle usernames containing double quotes.

- [PS-11273](https://perconadev.atlassian.net/browse/PS-11273): Fixed an issue where the server could cause a sudden exit during a failed or have an aborted startup when the `audit_log_filter` component was enabled.

- [PS-11291](https://perconadev.atlassian.net/browse/PS-11291): Fixed telemetry tests that were failing on macOS.

- [PS-11498](https://perconadev.atlassian.net/browse/PS-11498): Fixed an issue where the audit log filter recorded each disconnect event twice when the thread pool was enabled.

- [PS-11547](https://perconadev.atlassian.net/browse/PS-11547): Removed the `libcoredumper` library from ARM packages.

- [PS-11562](https://perconadev.atlassian.net/browse/PS-11562): Fixed an issue where `audit_log_read()` did not work when audit logs were stored outside the data directory.

- [PS-11593](https://perconadev.atlassian.net/browse/PS-11593): Improved performance by reducing how often the server locks the access control (ACL) cache, which now happens only when external roles change.

- [PS-11850](https://perconadev.atlassian.net/browse/PS-11850): Fixed an issue in InnoDB that could occur when the buffer pool was resized while pages were being read.

- [PS-11897](https://perconadev.atlassian.net/browse/PS-11897): Fixed an issue where the OpenID Connect authentication client plugin kept using the token file setting from an earlier session.

- [PS-11925](https://perconadev.atlassian.net/browse/PS-11925): Updated the KMIP client library with recent fixes, including reduced copying of key material in the `keyring_kmip` backend.

- [PS-11926](https://perconadev.atlassian.net/browse/PS-11926): Added the missing `AUDIT_ADMIN` privilege check to the `audit_log_encryption_password_get()`, `audit_log_encryption_password_set()`, `audit_log_read()`, and `audit_log_read_bookmark()` UDFs, which previously could be called by any authenticated account.

- [PS-11938](https://perconadev.atlassian.net/browse/PS-11938): The `asynchronous_connection_failover_add_managed()` function now rejects non-constant values for the managed type and managed name arguments, and returns an error instead.

- [PS-11985](https://perconadev.atlassian.net/browse/PS-11985): Fixed incorrect access to Group Replication flow control status variables.

- [PS-11991](https://perconadev.atlassian.net/browse/PS-11991): Fix versioning schema

## Builds and packaging

Percona Server for MySQL releases include a mixture of PGO and non-PGO builds. Where Profile-Guided Optimization (PGO) is enabled, the compiler uses runtime profiling data from representative workloads to guide optimization, which can improve throughput and reduce latency compared with non-PGO builds.

- See [Profile-Guided Optimization (PGO) and non-PGO builds](../pgo.md) for benefits, considerations, and which build you receive for your platform.
